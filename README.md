## ⚡ Quick Start

### 1. Clone the repo
```bash
git clone https://github.com/razangit5-pixel/python_course.git
cd python_course
```

### 2. Create a virtual environment
```bash
python -m venv venv
source venv/bin/activate        # macOS/Linux
venv\Scripts\activate           # Windows
```

### 3. Launch Jupyter
```bash
jupyter notebook
```
